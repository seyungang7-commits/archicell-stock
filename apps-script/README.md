# ARCHICELL 재고관리 — Apps Script 코드 보관

구글 시트 "ARHCICELL 공장 재고관리"의 확장 프로그램 → Apps Script에 들어가는 코드입니다.
이 폴더는 보관용이며, GitHub Pages 앱(index.html)은 이 파일을 직접 쓰지 않습니다.

- `Code.gs` — 서버 코드 (v3.10: 품목명 규칙(종류에 크기 숫자가 있으면 중복 삭제, 실버 생략) · 크기 자동 (30x30) · 기록 메모 수정 `updateLogMemo` / v3.9: v3.8 uiMutate + 사진 폴더를 이름 검색 없이 ID로 사용 · 드라이브 권한 오류 수정 · 권한 승인용 `setupPhotoFolder`)
- `Index.html` — 화면 코드 (v3.10: 관리 화면 가로 배치(품목 등록·수정 위, 재고 실사·조정은 접기) · 품목명 규칙 · 크기 자동 괄호 · QR 라벨(M코드 맨 위, "찍으면 입고·출고" 삭제) · 현황 색상 그룹 제목 · 기록 메모 추가·수정 / v3.9.10: 현황 목록 정렬 — 프로파일 먼저, 실버→블랙 색상별, 크기 작은 순(2020→2040→3030→3060→6060), 색상 구분 제목 / v3.9.9: 현황 오른쪽 패널 정리 — 오늘 요약 한 줄, 보충 필요를 위로(없으면 한 줄), 최근 입출고에서 취소·기초재고 숨김, 글씨 키움 / v3.9.8: 입출고 기록 화면 — 날짜·시간 두 줄, 취소·기초재고 기본 숨김(보기 스위치), 기간 버튼, 내 기록만, 더 보기, 엑셀(CSV) 내려받기 / v3.9.7: 입출고 기록 화면 개선(품목명 중심·검색 확장·휴대폰 카드·건수 요약) / v3.9.6: 휴대폰 가운데 자재관리 표시 삭제 / v3.9.5: 휴대폰 가운데 글자를 로고 글꼴로 / v3.9.4: 휴대폰 헤더 로고는 심볼만 / v3.9.3: 휴대폰 메뉴를 ☰ 아래 작은 메뉴로, 이름은 글자, 나가기는 붉은 글자 / v3.9.2: 휴대폰 헤더 왼쪽 로고·가운데 ARCHICELL·오른쪽 메뉴, PC 자재관리 통합시스템 / v3.9.1: 글씨체 Pretendard, 굵기·대비 완화, 사진 영역 가로 배치, M코드 품목명 위 표시 / v3.9: 회사 로고 헤더(휴대폰은 정중앙) · 여백/요약 카드/재고 목록 정리 · 품목 사진 간편 등록(파일 선택·Ctrl+V·끌어다 놓기))
- `QRLib`, `appsscript.json`은 Apps Script에 있는 그대로 사용합니다.

## 적용 방법
1. Apps Script에서 `Code.gs`, `Index.html` 내용을 이 파일로 통째로 교체 → 저장
2. 배포 → 배포 관리 → 연필(수정) → 새 버전 → 배포

(화면은 GitHub Pages 앱이 배포된 Apps Script에서 받아오므로, 위 2단계만 하면 반영됩니다. GitHub Pages 쪽 index.html은 바꿀 필요 없습니다.)

비밀번호는 코드에 없고 Apps Script의 스크립트 속성에만 있습니다.

## v3.9 적용 순서 (사진 권한 포함)
1. Apps Script의 `Code.gs`, `Index.html`을 이 폴더 파일로 통째로 교체 → 저장
2. 프로젝트 설정 → "편집기에서 appsscript.json 매니페스트 파일 표시" 체크 → appsscript.json에 `"oauthScopes"`가 있으면 목록에 `"https://www.googleapis.com/auth/drive"` 한 줄 추가
3. 편집기 위쪽 함수 목록에서 `setupPhotoFolder` 선택 → 실행 → 권한 승인
4. 배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포 (웹 앱 주소는 그대로)

## v3.10 적용 순서 (Code.gs와 Index.html 둘 다 교체)
1. Apps Script의 `Code.gs`, `Index.html`을 이 폴더 파일로 통째로 교체 → 저장
2. 배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포
- 기록 메모 수정 버튼은 Code v3.10이 배포되어야 나타납니다(이전 메모는 시트 셀 메모에 남습니다).
